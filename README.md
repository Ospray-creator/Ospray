# FineINK IDE bootstrap

Этот репозиторий содержит зачаточную структуру для форка VS Code под названием FineINK IDE. В нем хранится базовый product.json для ребрендинга и черновая версия расширения `ai-core`, которая реализует:

- Chat Participant, подключаемый к VS Code Chat и работающий со streaming API, совместимым с OpenAI/Ollama/LM Studio.
- Команды для открытия чата, настройки модели и сохранения API ключа через SecretStorage.
- Вкладку «История чатов» в боковой панели с хранением последних запросов в `globalState`.
- Заготовку MCP-клиента, запускающего внешний процесс по настройкам пользователя.

## Структура
- `source/product.json` — настройки бренда FineINK.
- `source/extensions/ai-core` — исходники расширения FineInk AI Core.
- `source/README-FineINK.md` — инструкция по запуску и настройке.

## Следующие шаги
См. `source/README-FineINK.md` для инструкции по dev-запуску на Windows. Для дальнейшего развития предстоит интеграция MCP-инструментов, улучшение UX чата и подготовка установщика.
